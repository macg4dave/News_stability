## If code or assets are imported later

Whisper's inspected source headers specify GPL-3.0-or-later. Its
[attribution](https://github.com/Nyancat-Labs/whisper_feed/blob/2fadadd28524012d055b406b6f38c8f2720b694a/ATTRIBUTION.md)
retains Neo Feed, HomeFeeder, and other inherited credits. Before adapting any
protected implementation, establish compatible licensing for the covered work,
retain upstream/inherited notices, identify modifications, ship the full
[license](https://github.com/Nyancat-Labs/whisper_feed/blob/2fadadd28524012d055b406b6f38c8f2720b694a/LICENSE),
and arrange complete corresponding source and build/install material for the
applicable distribution. Translating Kotlin into JavaScript is not a way to
avoid these requirements. Browser-delivered source is distributed too.

Fluent Reader's
[BSD-3-Clause license](https://github.com/yang991178/fluent-reader/blob/5912070309759eff37204a5046caba3c780fa4c0/LICENSE)
names Copyright (c) 2020 Haoyuan Liu. An import must retain the copyright,
conditions, and disclaimer in source and reproduce them with binary
distributions; names cannot be used to imply endorsement. Review dependencies
and separately licensed assets before copying them.

For every actual import, record the exact revision, source path, local destination,
copyright, license, inherited notices, and changes. Preserve headers; put full
license/NOTICE texts in `licenses/`; update `THIRD_PARTY_NOTICES.md` and the explicit
inventory in `scripts/update_notices.py`; regenerate and check the public bundle
and manifest. Verify source availability and compatibility before distribution.
Adding an unlisted license file alone does not update the public bundle.

The existing Miniflux, Fusion, Shiori, Memos, Go, and module licenses remain in
[the notices](../THIRD_PARTY_NOTICES.md). This review does not change the project's
own distribution license or claim permission to reuse third-party trademarks.

## NewsBlur contract review

The common story adapter was checked against
[NewsBlur story formatting](https://github.com/samuelclay/NewsBlur/blob/1b8fb1ace4d20f1e750b3bbdfb6f127d6a0d74d9/apps/rss_feeds/models.py#L3143).
It supplies `image_urls`, `secure_image_urls`, and epoch-seconds
`story_timestamp` (currently a string). We adapt fields rather than copying
implementation. Installed-version behavior still needs separate acceptance.
